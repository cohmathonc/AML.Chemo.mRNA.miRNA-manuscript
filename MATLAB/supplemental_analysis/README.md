# Multiomic state-transition model and manuscript figure generation 

## Overview
This directory contains any remaining code not included in [`MATLAB`](../MATLAB) required to reproduce the remaining analysis and supplemental figures from the manscript.  

## :scroll: compute_msd.m
Code to compute the mean-squared displacement (MSD) analysis and generate Figure S1 A,B.

## :file_folder: FigureS2_stateSpace_vs_DoseFactor
Code to generate the heatmaps in Figure S2 A,B. Run the script: `run_heatmap_statespace_vs_doseFactor.m`.  
**Note:** Modify the parameters gamma and T within the script to generate heatmaps as in Figure S2 A,B. 

## :file_folder: FigureS3_stateSpace_vs_Gamma
Code to generate the heatmaps in Figure S3. Run the script: `run_heatmap_statespace_vs_gamma.m`.
