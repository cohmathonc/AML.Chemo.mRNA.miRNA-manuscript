# Multiomic state-transition model and manuscript figure generation 
Mathematical and computational framework and figure-generation pipeline accompanying the manuscript.

## Overview
This directory contains all code required to reproduce all findings and figures presented in the associated manuscript. 

## :warning: Note: Data Requirements
Running this code requires data imported from the data file 'm_miRNA_combined_all.csv'. 

This data file is generated by the script "Chemo_AML_Analysis.R" file located in the [`R`](../R) folder. Please run this script before executing any downstream analyses or figure-generation workflows.

🚧 Public data deposit in progress. Accession number will be provided upon assignment.🚧

## ▶️ Instructions on how to run code
1. Run `Chemo_AML_Analysis.R` to generate `m_miRNA_combined_all.csv`
2. Add `m_miRNA_combined_all.csv` inside the MATLAB folder
3. Run the `main_analysis.m` file
