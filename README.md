# Multiomic State-Transitions Reveal Post-Treatment Transcriptome Desynchronization in Acute Myeloid Leukemia
Code repository accompanying the manuscript: https://doi.org/10.64898/2026.05.20.726707.
This repository contains all code used for data processing, statistical analyses, mathematical modeling and figure generation presented in the manuscript.

## MATLAB
All multiomic state-transition modeling, treatment vector analysis and figure generation (Main Figures 1 & 2).

## R
Scripts for RNA-seq and miRNA-seq data processing, quality control, differential expression analysis, statistical modeling, and figure generation (Main Figures 3, 4, & 5).
